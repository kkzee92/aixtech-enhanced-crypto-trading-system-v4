# Definition of Done

A change is Done when:
1. CI is green (tests, coverage threshold, secret scan stub, license check).
2. Human reviewer has approved (checklist in harness/review-checklist.md if present).
3. AI-disclosure log updated if AI-assisted.
4. No secrets, private keys, or production personal data introduced.
5. Paper-only constraint preserved.

This aligns with the AI-agent harness principles from zeekiankok92.
